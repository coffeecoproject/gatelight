# claude/test-home

测试把家目录换成自己的临时目录，不读也不改用户真实的那份。先于插件改名（会在会话开始时更新 `~/.local/bin/testpace`）单独落地。

## 证明方式

- 测试不读也不改用户真实的家目录 —— 看代码加清单：`plugin/tests/helpers.ts` 在算测试起命令用的环境之前，把 `HOME` 换成临时目录，进程里直接调的代码和测试起的命令都用它；只加了几行，原有的没动。写不成测试（要拿真实的家目录来验），加了清单条目 `outside-repo-writes`
- 跑命令：改完跑相关测试、放水检查，前后 `ls -l ~/.local/bin/testpace` 的修改时间没变
- 换了家目录后 npm 接着用用户的下载缓存和设置 —— 跑命令：真起 layermap 的测试（`plugin/tests/wall/database.test.ts`、`check.test.ts`）不带这两行时卡在 `npm install layermap`（整组 8 分钟没跑完），带上后 33 秒通过

## 放水理由

- `plugin/tests/helpers.ts`：只加不改。加了把 `HOME` 换成临时目录的三行和跑完删掉它的一行，换之前把 npm 的下载缓存和用户设置指回用户原来的那份（两行），原有的辅助函数和环境变量的处理没动。原来有的测试读到的"固定命令入口放没放"从这台机器的实际情况变成"没放"（要测入口的测试本来就另给家目录），没有测试的期望因此要改
