# claude/review-remind-once

复查中的提醒反复拦。停止门在复查中不催证明和放水检查，只提醒"复查还开着"，设计（测试写法方案 5.7）和文件头注释写的都是只提醒一次；实现里这条提醒的记号带着测试这一侧的样子，复查中每改一次测试，样子变了，下次收尾又拦一次。改法：提醒的记号按这次复查记（哪次改动的复查、什么时候开的，`plugin/src/craft/session.ts`），不带改动的样子。提醒还是走拦截，没降成只给用户看的提示：agent 忘了跑 `testcraft review done` 就收尾时靠这一次拦住。

## 证明方式

- 一次复查只提醒一次：复查中接着再改测试不再提醒；结束后另开一次复查，再改测试才再提醒一次 —— 新测试 `plugin/tests/craft/review.test.ts` 的"一次复查只提醒一次：复查中接着再改测试不再提醒；结束后另开一次复查，再改测试才再提醒一次"（改之前在第二次改测试后那一步失败）
- 复查中第一次改测试照常提醒、不催证明，复查结束后还缺的照常拦，复查中清单照常拦 —— 已有检查（`plugin/tests/craft/review.test.ts` 原有的几条都通过，没动）
