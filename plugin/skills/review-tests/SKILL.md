# 请检查员复查测试

另起一个 agent（Agent 工具，general-purpose）当检查员。它没看过这次的对话，只看材料，所以结论不会被写测试的人带着走。

## 给检查员的材料

- 这次改动里测试这一侧的 diff（`git diff <分叉点>` 限定在测试、测试辅助文件和测试数据），测试配置、依赖、测试约定文件的 diff，和测试守的代码的 diff。
- 改动记录 `.testcraft/changes/<分支名>.md`。
- `testcraft prove` 和 `testcraft weaken` 的输出（含改坏证明里"没被发现的破坏"，证明成立时也会列出抓到之前没发现的几处）。
- `testcraft checklist` 的输出，和命中条目的那些文件的 diff（输出里"改到了"列的文件）。

## 给检查员的要求（原样放进提示）

> 你是测试检查员。只挑四类问题，别的不管，**不评风格、命名、格式**：
>
> 1. **糊弄**：同义反复（断言的就是刚设好的值）；只断言有返回值、不抛异常；把实现逻辑抄进期望值；mock 返回 X 再断言 X；替身用在外部第三方服务和浏览器端才有的状态以外的地方；测内部做法、和实现耦合；`testcraft prove` 里"没被发现的破坏"说明某个情况没测到；修 bug 的测试红的原因不是这个 bug；测试代码里新加了固定等待（`sleep`、`waitForTimeout`、等几秒）、重试（循环重试，测试文件里设的重试如 `test.describe.configure({ retries })`、`jest.retryTimes()`）、调大了已有等待的超时，或者把断言放宽到几种结果都算对（这些写法只会把时好时坏藏起来，改动记录里写了原因也照样算）。新写的等具体条件的写法（元素出现、请求返回，`expect.poll`、`toPass`、`waitFor`，给本来就慢的一步单独设超时）、零延迟的 `setTimeout(r, 0)`（让排队的回调先跑完）不算；配置文件里的重试和超时归第 3 类，这里不重复报。
> 2. **多余**：说不出守哪条规则；同一条规则在几层重复测；低一层就抓得到的规则放到了页面测试里；测了框架、数据库本身、原样转交的代码、配置常量、不可能发生的情况。
> 3. **放水理由对不上**：改动记录"放水理由"里技术调整的那几处（`testcraft weaken` 输出里改断言写法、测试跟着代码改了接法、改测试配置和数据、改依赖和约定的，用户不过目这些），对照 diff 看：理由说的事 diff 里没有；或者测试检查的东西其实变少、变宽了（期望值放宽、检查删了没有替代、超时和重试放大）；钱、权限、数据的检查有任何放松。"测试跟着代码改了接法"的那几个文件，diff 只该改路径、导入、命令、名字，顺带改了期望值或检查的，算对不上。
>    要用户过目的那几处（删测试、让测试不跑、程序的做法变了、删了或放宽了清单条目），改动记录"## 给用户过目"每行对照 diff 看：写的原来守什么、现在守什么和 diff 对不上；不是用户看得懂的白话（写了实现细节、函数名、代码）；把放松说轻了（删了说成挪了、不查了说成调整了、规则变了说成整理）。合并前用户只看这一行做决定，写偏了用户就会同意他没想同意的事。
> 4. **清单没真查**：改动记录"## 清单"里每条命中的条目，对照条目的"怎么查"和 diff 看：写的查法和条目要求的对不上（条目要拿老数据跑一遍，记录里只说"看过代码"）；结论和 diff 对不上（说加了默认值，diff 里没有）；只写了"已查""没问题"，说不出查了什么。
>
> 每条结论写：哪个测试（文件和测试名）、问题是什么、依据（指出代码或输出里的哪一处）。没有依据的不写。认为某个测试多余要删时，说明删掉后哪个测试还守着这条规则。没有问题就说没有问题。

## 拿到结论后

- 糊弄的：改测试，重跑 `testcraft prove`。
- 藏起时好时坏的：去掉等待、重试，改回超时和断言，按 `testpace:write-tests` 的"测试时好时坏"找原因修。
- 清单没真查的：按条目的"怎么查"重新查，改写那一行；查出问题的先停下来告诉用户。
- 给用户过目的说明对不上、不是白话、说轻了的：照 diff 重写那一行。
- 放水理由对不上的：改回去；确实要这样改的，当业务上的事用白话告诉用户、问用户，用户同意了再把理由写清楚。
- 多余的：删之前，在改动记录"守的代码"一段写明剩下的测试守的代码，跑 `testcraft prove <剩下的测试文件>` 确认它们照样能抓错；删除写进"放水理由"。
- 检查员提问题、修、再查，**最多两轮**。两轮后还有问题，停下来，用白话告诉用户卡在哪，不要降低标准放行。
